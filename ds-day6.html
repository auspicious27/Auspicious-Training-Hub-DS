Overview

This page follows the exact Day 6 syllabus. It is written in simple English so the teacher can read and explain it directly in class.

Practical Code

Run this code in Jupyter Notebook. Read the code first, run it, check the output, and then explain how the input becomes the final result.

workflow = ["Collect Data", "Clean Data", "Analyze Data", "Train Model", "Evaluate Model"]
for step in workflow:
    print(step)

Expected Output

Collect Data
Clean Data
Analyze Data
Train Model
Evaluate Model

Detailed Code Explanation

LineCodeExplanation
1workflow = ["Collect Data", "Clean Data", "Analyze Data", "Train Model", "Evaluate Model"]This line stores a value in a variable. A variable is like a named box in memory. We can use this value again in later lines. In data science, variables can store datasets, features, labels, models, scores, and file paths. Good variable names make the program easy to understand. This line helps organize the data flow.
2for step in workflow:This line starts a loop. A loop repeats a task automatically. Loops are useful when we need to process many numbers, rows, students, images, or workflow steps. Without a loop, we would have to write the same code many times. This line makes the program shorter and more scalable. It is a core part of practical programming.
3print(step)This line displays output on the screen. In Jupyter Notebook, it gives immediate feedback to the learner. It helps the teacher show what the program calculated or processed. Print statements are also useful for debugging. In real projects, they can show summaries, predictions, scores, and status messages. This line makes the result visible.
