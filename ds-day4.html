Practical Code

Is code ko Jupyter Notebook me run karna hai. Code simple rakha gaya hai taaki learner concept ko easily connect kar sake.

student_name = "Rahul"
marks = [88, 76, 92]
total = sum(marks)
percentage = total / 300 * 100
grade = "A" if percentage >= 75 else "B"
print(student_name, total, percentage, grade)
