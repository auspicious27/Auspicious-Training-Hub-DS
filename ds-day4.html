Practical Code: Student Marks Management System

Is practical ko Jupyter Notebook me run karna hai. Pehle code ko read karo, phir run karo, phir output observe karo. Teacher ko output ke baad explain karna hai ki input data kaise process hua and final result kaise bana.

student = "Rahul"
subjects = {"Python": 88, "Statistics": 76, "Math": 92}
total_marks = sum(subjects.values())
maximum_marks = len(subjects) * 100
percentage = (total_marks / maximum_marks) * 100

if percentage >= 90:
    grade = "A+"
elif percentage >= 75:
    grade = "A"
elif percentage >= 60:
    grade = "B"
else:
    grade = "C"

print("Student:", student)
print("Total:", total_marks)
print("Percentage:", round(percentage, 2))
print("Grade:", grade)

Expected Output

Student: Rahul
Total: 256
Percentage: 85.33
Grade: A
