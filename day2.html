Variables in Python

What are Variables?

A variable is a named container that stores data in memory. Think of it as a labeled box where you can put values.

# Creating variables
name = "Sayeed"          # String variable
age = 22                 # Integer variable
height = 5.8             # Float variable
is_student = True        # Boolean variable

print(name, age, height, is_student)
Output: 
Sayeed 22 5.8 True

Key Points about Variables:

  • No need to declare type (dynamically typed)
  • Value can be changed anytime
  • Variable is created when you first assign a value
  • Use = for assignment
# Variables can be reassigned
x = 10
print(x)    # 10

x = "Hello"
print(x)    # Hello (type changed from int to str!)

# Multiple assignment
a, b, c = 1, 2, 3
print(a, b, c)  # 1 2 3

# Same value to multiple variables
x = y = z = 100
print(x, y, z)  # 100 100 100

  • Classes: PascalCase (e.g., StudentData)
  • Constants: UPPER_CASE (e.g., MAX_SIZE)

Type Casting

Converting Between Data Types

Type casting is converting one data type to another.

# String to Integer
age_str = "25"
age_int = int(age_str)
print(age_int + 5)      # 30

# String to Float
price_str = "99.99"
price = float(price_str)
print(price)            # 99.99

# Integer to String
num = 100
num_str = str(num)
print("Score: " + num_str)  # Score: 100

# Float to Integer (truncates decimal)
pi = 3.99
print(int(pi))          # 3 (not rounded, just cuts decimal)

# Integer to Float
x = 10
print(float(x))         # 10.0

# Boolean conversions
print(int(True))        # 1
print(int(False))       # 0
print(bool(1))          # True
print(bool(0))          # False
print(bool(""))         # False (empty string)
print(bool("Hello"))    # True (non-empty string)

Common Error: You cannot convert non-numeric strings to int/float

# This will cause ValueError!
# num = int("hello")  # Error!
# num = int("12.5")   # Error! Use float() first

Basic Python Syntax

Python Syntax Rules

1. Indentation is Mandatory

# Python uses indentation for code blocks
if True:
    print("This is indented")  # 4 spaces
    print("Same block")

# Wrong! Will cause IndentationError
# if True:
# print("No indentation")  # Error!

2. No Semicolons Needed

# Python doesn't need semicolons
x = 10
y = 20
print(x + y)

# Semicolons CAN be used but not recommended
a = 1; b = 2; c = 3  # Valid but ugly

3. Case Sensitivity

Name = "Alice"
name = "Bob"
NAME = "Charlie"
# All three are different variables!

print(Name)   # Alice
print(name)   # Bob
print(NAME)   # Charlie

4. Line Continuation

# Using backslash
total = 10 + 20 + 30 + \
        40 + 50 + 60

# Using parentheses (preferred)
total = (10 + 20 + 30 +
         40 + 50 + 60)

print(total)  # 210

Important Notes & Deep Dive

Variable Memory Concept

When you write x = 10, Python does the following behind the scenes:

  1. Creates an integer object with value 10 in memory
  2. Creates a variable name 'x' (like a label/tag)
  3. Attaches the label 'x' to that object
# Understanding variable references
x = 10      # x points to object 10
y = x       # y also points to same object 10
print(id(x))  # Memory address of x
print(id(y))  # Same address! Both point to 10

x = 20      # Now x points to NEW object 20
print(x)    # 20
print(y)    # Still 10! (y still points to original object)

Key Insight: In Python, variables are just references (labels) pointing to objects in memory. They don't "contain" the value directly.

Data Type Deep Dive

Integer (int) — Unlimited Size!

  • Python integers have NO size limit (unlike C/Java where int max is ~2 billion)
  • x = 99999999999999999999999999999 → Works perfectly in Python!
  • Supports binary: 0b1010 = 10, Octal: 0o12 = 10, Hex: 0xA = 10

Float — Decimal Numbers

  • Stored as 64-bit double precision (limited accuracy)
  • 0.1 + 0.2 = 0.30000000000000004 (NOT exactly 0.3!)
  • Scientific notation: 1.5e3 = 1500.0, 2.5e-2 = 0.025

String (str) — Immutable!

  • Strings cannot be changed after creation (immutable)
  • s = "hello"; s[0] = "H" → TypeError!
  • Instead: s = "H" + s[1:] → Creates new string "Hello"
  • Triple quotes for multi-line: """line1\nline2"""
# Type checking and conversion examples
x = "42"
print(type(x))        # <class 'str'>
print(isinstance(x, str))  # True

# Safe conversion with error handling
user_input = "hello"
try:
    num = int(user_input)
except ValueError:
    print("That's not a number!")

# f-string formatting tricks
price = 1234567.89
print(f"Price: ₹{price:,.2f}")    # Price: ₹1,234,567.89
print(f"Percentage: {0.856:.1%}")  # Percentage: 85.6%
name = "python"
print(f"{'python':>10}")           # Righ aligned:     python
print(f"{'python':<10}")           # Left aligned: python
