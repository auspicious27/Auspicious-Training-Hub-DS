Practical Code

Is code ko Jupyter Notebook me run karna hai. Code simple rakha gaya hai taaki learner concept ko easily connect kar sake.

from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

y_true = [100, 150, 200]
y_pred = [110, 145, 190]
print(mean_absolute_error(y_true, y_pred))
print(mean_squared_error(y_true, y_pred))
print(r2_score(y_true, y_pred))

Expected Output

MAE, MSE, and R2 score values.
