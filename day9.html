Matplotlib Basics

Introduction to Matplotlib

Matplotlib is the foundational plotting library in Python. It provides complete control over every aspect of a figure.

import matplotlib.pyplot as plt
import numpy as np

# Basic line plot
x = np.linspace(0, 10, 100)
y = np.sin(x)

plt.figure(figsize=(10, 6))
plt.plot(x, y, color='#ff1b6b', linewidth=2, label='sin(x)')
plt.title("Sine Wave", fontsize=16)
plt.xlabel("X axis")
plt.ylabel("Y axis")
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

# Customizing plots
plt.figure(figsize=(10, 6))
plt.plot(x, np.sin(x), 'r-', label='sin(x)')
plt.plot(x, np.cos(x), 'b--', label='cos(x)')
plt.title("Trigonometric Functions")
plt.xlabel("Angle (radians)")
plt.ylabel("Value")
plt.legend(loc='upper right')
plt.grid(True)
plt.tight_layout()
plt.savefig("plot.png", dpi=150)
plt.show()

Seaborn Basics

Statistical Visualization with Seaborn

Seaborn is built on top of Matplotlib and provides beautiful statistical graphics with less code.

import seaborn as sns
import pandas as pd

# Set style
sns.set_style("darkgrid")
sns.set_palette("husl")

# Load sample dataset
tips = sns.load_dataset("tips")

# Distribution plot
plt.figure(figsize=(8, 5))
sns.histplot(tips["total_bill"], kde=True, color='#ff1b6b')
plt.title("Distribution of Total Bill")
plt.show()

# Count plot (for categorical data)
plt.figure(figsize=(8, 5))
sns.countplot(x="day", data=tips, palette="viridis")
plt.title("Visits by Day")
plt.show()

# Box plot (shows distribution + outliers)
plt.figure(figsize=(8, 5))
sns.boxplot(x="day", y="total_bill", data=tips)
plt.title("Bill Distribution by Day")
plt.show()

Chart Types

Common Visualization Types

1. Line Chart — Trends over time

months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun']
sales = [150, 200, 180, 250, 300, 280]

plt.figure(figsize=(10, 5))
plt.plot(months, sales, marker='o', color='#ff1b6b', linewidth=2)
plt.fill_between(months, sales, alpha=0.1, color='#ff1b6b')
plt.title("Monthly Sales Trend")
plt.ylabel("Sales (units)")
plt.show()

2. Bar Chart — Comparing categories

subjects = ['Math', 'Science', 'English', 'Hindi', 'CS']
marks = [85, 92, 78, 88, 95]

plt.figure(figsize=(10, 5))
bars = plt.bar(subjects, marks, color=['#ff1b6b', '#667eea', '#f093fb', '#4facfe', '#43e97b'])
plt.title("Subject-wise Marks")
plt.ylabel("Marks")
plt.ylim(0, 100)

# Add value labels on bars
for bar, mark in zip(bars, marks):
    plt.text(bar.get_x() + bar.get_width()/2, bar.get_height() + 1, 
             str(mark), ha='center', fontweight='bold')
plt.show()

3. Histogram — Distribution

data = np.random.normal(70, 15, 200)  # Mean=70, Std=15

plt.figure(figsize=(10, 5))
plt.hist(data, bins=20, color='#667eea', edgecolor='black', alpha=0.7)
plt.axvline(np.mean(data), color='red', linestyle='--', label=f'Mean: {np.mean(data):.1f}')
plt.title("Marks Distribution")
plt.xlabel("Marks")
plt.ylabel("Frequency")
plt.legend()
plt.show()

4. Scatter Plot — Relationships

hours = np.random.uniform(1, 10, 50)
marks = 20 + 8 * hours + np.random.normal(0, 5, 50)

plt.figure(figsize=(10, 6))
plt.scatter(hours, marks, c=marks, cmap='RdYlGn', s=80, alpha=0.7)
plt.colorbar(label='Marks')
plt.xlabel("Hours Studied")
plt.ylabel("Marks Obtained")
plt.title("Study Hours vs Marks")
plt.show()

5. Pie Chart — Proportions

grades = ['A+', 'A', 'B', 'C', 'D', 'F']
counts = [5, 12, 15, 10, 6, 2]
colors = ['#ff1b6b', '#667eea', '#f093fb', '#4facfe', '#ffa726', '#ef5350']

plt.figure(figsize=(8, 8))
plt.pie(counts, labels=grades, colors=colors, autopct='%1.1f%%', 
        startangle=90, explode=[0.05]*6)
plt.title("Grade Distribution")
plt.show()

Correlation Matrix

Understanding Feature Relationships

import seaborn as sns
import pandas as pd

# Create sample data
data = pd.DataFrame({
    'Hours_Studied': np.random.uniform(1, 10, 100),
    'Attendance': np.random.uniform(50, 100, 100),
    'Previous_Score': np.random.uniform(40, 95, 100),
    'Sleep_Hours': np.random.uniform(4, 9, 100),
})
data['Final_Score'] = (data['Hours_Studied'] * 5 + 
                       data['Attendance'] * 0.3 + 
                       data['Previous_Score'] * 0.4 + 
                       np.random.normal(0, 5, 100))

# Correlation matrix
corr = data.corr()
print("Correlation Matrix:")
print(corr)

# Heatmap visualization
plt.figure(figsize=(8, 6))
sns.heatmap(corr, annot=True, cmap='RdYlBu_r', center=0, 
            fmt='.2f', square=True)
plt.title("Feature Correlation Heatmap")
plt.tight_layout()
plt.show()

# Interpretation:
# +1: Perfect positive correlation
#  0: No correlation
# -1: Perfect negative correlation

Correlation Values:

  • 0.7 to 1.0: Strong positive correlation
  • 0.3 to 0.7: Moderate positive correlation
  • 0.0 to 0.3: Weak/No correlation
  • -0.3 to -0.7: Moderate negative correlation
  • -0.7 to -1.0: Strong negative correlation

Exploratory Data Analysis (EDA)

Complete EDA Process

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# EDA Workflow
def perform_eda(df):
    print("="*50)
    print("  EXPLORATORY DATA ANALYSIS")
    print("="*50)
    
    # 1. Basic Info
    print(f"\n1. SHAPE: {df.shape}")
    print(f"\n2. COLUMNS: {list(df.columns)}")
    print(f"\n3. DATA TYPES:\n{df.dtypes}")
    
    # 4. Missing Values
    print(f"\n4. MISSING VALUES:\n{df.isnull().sum()}")
    
    # 5. Statistical Summary
    print(f"\n5. STATISTICAL SUMMARY:\n{df.describe()}")
    
    # 6. Duplicates
    print(f"\n6. DUPLICATE ROWS: {df.duplicated().sum()}")
    
    # 7. Unique values for categorical columns
    cat_cols = df.select_dtypes(include='object').columns
    for col in cat_cols:
        print(f"\n7. UNIQUE in '{col}': {df[col].nunique()} values")
    
    return df

# Call EDA
# df = pd.read_csv("your_data.csv")
# perform_eda(df)

EDA Checklist:

  • Check shape, columns, data types
  • Identify and handle missing values
  • Check for duplicates
  • Statistical summary (mean, median, std)
  • Distribution of numerical features (histograms)
  • Distribution of categorical features (bar plots)
  • Correlation between features (heatmap)
  • Identify outliers (box plots)
  • Relationships between features (scatter plots)
  • Document key insights

Day 9 Assessment

Q1: Which library is used for statistical plots?

Show Answer

Seaborn — Built on Matplotlib, provides beautiful statistical graphics.

Q2: What chart is best for showing trends over time?

Show Answer

Line Chart — Shows how values change over a continuous period.

Q3: What does a correlation of -0.8 mean?

Show Answer

Strong negative correlation — as one variable increases, the other decreases strongly.

Q4: What chart shows data distribution?

Show Answer

Histogram shows the frequency distribution of numerical data.

Q5: How to save a Matplotlib plot?

Show Answer

plt.savefig("filename.png", dpi=150) — Call before plt.show()

Q6: What is EDA?

Show Answer

Exploratory Data Analysis — The process of examining data to discover patterns, spot anomalies, and understand relationships before building models.

Q7: What does sns.heatmap() display?

Show Answer

A color-coded matrix showing correlation values between all numerical features. Darker colors = stronger correlations.

Q8: When to use scatter plot?

Show Answer

To visualize the relationship between two continuous numerical variables. Each point represents one observation.

Q10: What's the difference between plt.plot() and plt.scatter()?

Show Answer

plt.plot() creates a line connecting all points (good for trends). plt.scatter() shows individual data points without connecting them (good for relationships).
