Practical Code: Student Performance Dashboard

Is practical ko Jupyter Notebook me run karna hai. Pehle code ko read karo, phir run karo, phir output observe karo. Teacher ko output ke baad explain karna hai ki input data kaise process hua and final result kaise bana.

import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({"Name": ["Rahul", "Priya", "Aman"], "Score": [82, 94, 76], "Attendance": [88, 96, 80]})
df["Performance"] = (df["Score"] + df["Attendance"]) / 2
top_students = df.sort_values("Performance", ascending=False).head(2)

print(df)
print("Top Students")
print(top_students)

df.plot(x="Name", y="Performance", kind="bar")
plt.title("Student Performance Dashboard")
plt.show()

Expected Output

Student performance table, top students table, and bar chart.
