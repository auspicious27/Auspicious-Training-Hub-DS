Practical Code

Is code ko Jupyter Notebook me run karna hai. Code simple rakha gaya hai taaki learner concept ko easily connect kar sake.

import pandas as pd

df = pd.DataFrame({"Name": ["Rahul", "Priya", "Aman"], "Score": [82, 94, 76]})
top_performers = df.sort_values("Score", ascending=False)
print(top_performers)

Expected Output

Students sorted by score from highest to lowest.
