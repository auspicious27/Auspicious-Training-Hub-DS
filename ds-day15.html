Practical Code: Smart Attendance Record and Dashboard

Is practical ko Jupyter Notebook me run karna hai. Pehle code ko read karo, phir run karo, phir output observe karo. Teacher ko output ke baad explain karna hai ki input data kaise process hua and final result kaise bana.

import pandas as pd
import matplotlib.pyplot as plt

attendance = pd.DataFrame({"Student": ["Rahul", "Priya", "Aman"], "Status": ["Present", "Present", "Absent"]})
attendance.to_csv("attendance_report.csv", index=False)
summary = attendance["Status"].value_counts()
print(attendance)
print(summary)
summary.plot(kind="bar", title="Attendance Dashboard")
plt.show()

Expected Output

Attendance CSV file, status summary, and dashboard chart.
