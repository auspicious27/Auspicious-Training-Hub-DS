Practical Code

Run this code in Jupyter Notebook. Read the code first, run it, check the output, and then explain how the input becomes the final result.

import seaborn as sns
import matplotlib.pyplot as plt

df = sns.load_dataset("titanic")
sns.histplot(df["age"].dropna())
plt.title("Age Distribution")
plt.show()

Expected Output

Histogram chart of Titanic age distribution.
