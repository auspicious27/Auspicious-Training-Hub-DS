Practical Code

Is code ko Jupyter Notebook me run karna hai. Code simple rakha gaya hai taaki learner concept ko easily connect kar sake.

import seaborn as sns
import matplotlib.pyplot as plt

df = sns.load_dataset("titanic")
sns.histplot(df["age"].dropna())
plt.title("Age Distribution")
plt.show()

Expected Output

Histogram chart of Titanic age distribution.
