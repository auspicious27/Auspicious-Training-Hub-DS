Practical Code: EDA with Titanic-style Dataset

Is practical ko Jupyter Notebook me run karna hai. Pehle code ko read karo, phir run karo, phir output observe karo. Teacher ko output ke baad explain karna hai ki input data kaise process hua and final result kaise bana.

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

df = sns.load_dataset("titanic")
print(df.head())
print(df[["age", "fare", "survived"]].corr())

sns.histplot(df["age"].dropna(), kde=True)
plt.title("Age Distribution")
plt.show()

sns.scatterplot(data=df, x="age", y="fare", hue="survived")
plt.title("Age vs Fare")
plt.show()

Expected Output

Titanic dataset preview, correlation matrix, histogram, and scatter plot.
