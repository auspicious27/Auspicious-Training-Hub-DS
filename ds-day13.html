Practical Code: Face Detection using Laptop Webcam

Is practical ko Jupyter Notebook me run karna hai. Pehle code ko read karo, phir run karo, phir output observe karo. Teacher ko output ke baad explain karna hai ki input data kaise process hua and final result kaise bana.

import cv2

CAMERA_SOURCE = 0
face_detector = cv2.CascadeClassifier(cv2.data.haarcascades + "haarcascade_frontalface_default.xml")
camera = cv2.VideoCapture(CAMERA_SOURCE)
success, frame = camera.read()
camera.release()

if success:
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    faces = face_detector.detectMultiScale(gray, 1.2, 5)
    print("Faces detected:", len(faces))
else:
    print("Camera not working")

Expected Output

Faces detected: 1
