Practical Code: House Price Prediction System

Is practical ko Jupyter Notebook me run karna hai. Pehle code ko read karo, phir run karo, phir output observe karo. Teacher ko output ke baad explain karna hai ki input data kaise process hua and final result kaise bana.

import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, r2_score

df = pd.DataFrame({"Area": [1000, 1500, 2000, 2500], "Rooms": [2, 3, 3, 4], "Price": [50, 75, 100, 130]})
X = df[["Area", "Rooms"]]
y = df["Price"]
model = LinearRegression()
model.fit(X, y)
predictions = model.predict(X)
print("MAE:", mean_absolute_error(y, predictions))
print("R2 Score:", r2_score(y, predictions))

Expected Output

MAE and R2 score for the house price prediction model.
