Practical Code

Run this code in Jupyter Notebook. Read the code first, run it, check the output, and then explain how the input becomes the final result.

from sklearn.linear_model import LinearRegression

X = [[1000], [1500], [2000], [2500]]
y = [50, 75, 100, 125]
model = LinearRegression()
model.fit(X, y)
print(model.predict([[3000]]))

Expected Output

Predicted house price for 3000 area.
