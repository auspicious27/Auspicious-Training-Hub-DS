Day 6: Introduction to Data Science & Machine Learning

Understanding AI, ML, DL and the Data Science ecosystem

What is Data Science?

Understanding Data Science

Data Science is an interdisciplinary field that uses scientific methods, processes, algorithms, and systems to extract meaningful insights and knowledge from structured and unstructured data.

Data Science = Statistics + Programming + Domain Knowledge

  • Statistics: Understanding data patterns, probability, distributions
  • Programming: Python/R for data manipulation and modeling
  • Domain Knowledge: Understanding the business problem

Data Science Process

COLLECT

Gather raw data

→

PROCESS

Clean & analyze

→

INSIGHTS

Predictions & decisions

Real-World Example: Netflix

Netflix collects viewing data from millions of users → Processes it to find patterns → Recommends movies you'll likely enjoy. That's data science in action!

Artificial Intelligence (AI)

What is AI?

Artificial Intelligence is the broader concept of machines being able to carry out tasks in a way that we would consider "smart" — mimicking human intelligence.

Types of AI:

  • Narrow AI (Weak AI): Designed for specific tasks — Siri, Google Maps, Chess AI
  • General AI (Strong AI): Human-like intelligence across all tasks — doesn't exist yet
  • Super AI: Surpasses human intelligence — theoretical/futuristic

AI vs ML vs DL — The Hierarchy

AI (Largest circle) → Machine Learning (Subset of AI) → Deep Learning (Subset of ML)

  • AI: Any technique enabling machines to mimic human behavior
  • ML: AI that learns from data without explicit programming
  • DL: ML using neural networks with many layers

Machine Learning (ML)

What is Machine Learning?

Machine Learning is a subset of AI that enables systems to learn and improve from experience (data) without being explicitly programmed. Instead of writing rules, we feed data and let the algorithm find patterns.

Traditional Programming vs Machine Learning:

Traditional: Input + Rules → Output

Machine Learning: Input + Output → Rules (Model)

# Traditional approach - Manual rules
def is_spam(email):
    if "lottery" in email or "free money" in email:
        return True
    return False

# Machine Learning approach - Learn from data
# Feed thousands of spam/not-spam emails
# Algorithm learns the patterns automatically
# model.predict(new_email) → spam/not_spam

Key Concepts:

  • Training: Teaching the model using historical data
  • Features: Input variables (attributes) used for prediction
  • Labels: Output variable (what we want to predict)
  • Model: The learned pattern/function
  • Prediction: Using the model on new, unseen data

Deep Learning (DL)

What is Deep Learning?

Deep Learning is a subset of ML that uses artificial neural networks with multiple layers (hence "deep") to learn complex patterns from large amounts of data.

Machine Learning Workflow

End-to-End ML Pipeline

  1. Problem Definition: What are we trying to predict/solve?
  2. Data Collection: Gather relevant data (CSV, APIs, databases)
  3. Data Preprocessing: Clean data, handle missing values, encode categories
  4. Exploratory Data Analysis (EDA): Visualize and understand data patterns
  5. Feature Engineering: Create/select relevant features
  6. Model Selection: Choose appropriate algorithm
  7. Model Training: Feed data to the algorithm
  8. Model Evaluation: Test accuracy using metrics (MAE, R², accuracy)
  9. Model Tuning: Optimize hyperparameters
  10. Deployment: Put model into production
# Simplified ML workflow in Python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error

# 1. Load Data
data = pd.read_csv("dataset.csv")

# 2. Prepare Features (X) and Target (y)
X = data[["feature1", "feature2"]]
y = data["target"]

# 3. Split into Train and Test
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 4. Train Model
model = LinearRegression()
model.fit(X_train, y_train)

# 5. Predict & Evaluate
predictions = model.predict(X_test)
error = mean_absolute_error(y_test, predictions)
print(f"Mean Absolute Error: {error}")

Types of Machine Learning

Three Main Categories

1. Supervised Learning

Learning from labeled data (input-output pairs). The model learns the mapping from input to output.

  • Classification: Predict categories (Spam/Not Spam, Cat/Dog)
  • Regression: Predict numbers (House Price, Salary, Temperature)

Algorithms: Linear Regression, Decision Trees, Random Forest, SVM, KNN

2. Unsupervised Learning

Learning from unlabeled data. The model finds hidden patterns or groupings.

  • Clustering: Group similar items (Customer Segments)
  • Dimensionality Reduction: Reduce features (PCA)

Algorithms: K-Means, DBSCAN, Hierarchical Clustering, PCA

3. Reinforcement Learning

Learning through trial and error. Agent takes actions and receives rewards/penalties.

  • Examples: Game AI (AlphaGo), Robotics, Self-driving cars

Concepts: Agent, Environment, State, Action, Reward

Q1: What is the relationship between AI, ML, and DL?

Show Answer

AI is the broadest concept. ML is a subset of AI. DL is a subset of ML. DL ⊂ ML ⊂ AI

Q2: What type of ML is email spam detection?

Show Answer

Supervised Learning (Classification) — We have labeled data (spam/not spam) and predict categories.

Q3: What is the difference between Classification and Regression?

Show Answer

Classification: Predicts categories (Yes/No, Cat/Dog). Regression: Predicts continuous numbers (Price, Temperature, Age).

Q4: Name 3 real-world applications of Machine Learning

Show Answer

1) Netflix recommendations 2) Gmail spam filter 3) Self-driving cars 4) Voice assistants (Siri/Alexa) 5) Face unlock on phones

Q5: What is the main difference between Traditional Programming and ML?

Show Answer

Traditional: We write explicit rules. ML: The algorithm learns rules from data automatically.

Q6: What are Features and Labels in ML?

Show Answer

Features (X): Input variables used for prediction (e.g., area, rooms). Labels (y): Output variable we want to predict (e.g., price).

Q7: What is Unsupervised Learning? Give an example.

Show Answer

Learning from unlabeled data to find hidden patterns. Example: Customer segmentation — grouping customers by buying behavior without predefined categories.

Q8: List the steps in ML Workflow

Show Answer

1) Problem Definition 2) Data Collection 3) Data Preprocessing 4) EDA 5) Feature Engineering 6) Model Selection 7) Training 8) Evaluation 9) Tuning 10) Deployment

Q9: When would you use Deep Learning over regular ML?

Show Answer

Use DL when: Large dataset available, complex patterns (images, speech, text), GPU available, and automatic feature extraction is needed.

Q10: What Python libraries are used for ML?

Show Answer

Data: NumPy, Pandas. Visualization: Matplotlib, Seaborn. ML: Scikit-learn. DL: TensorFlow, PyTorch. CV: OpenCV.
