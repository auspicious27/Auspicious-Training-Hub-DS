Practical Code

Is code ko Jupyter Notebook me run karna hai. Code simple rakha gaya hai taaki learner concept ko easily connect kar sake.

from sklearn.linear_model import LinearRegression

X = [[1], [2], [3], [4]]
y = [40, 50, 60, 70]
model = LinearRegression()
model.fit(X, y)
print(model.predict([[5]]))

Expected Output

Predicted value for 5 hours.
