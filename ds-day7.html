Practical Code: Clean Student Dataset using NumPy and Pandas

Is practical ko Jupyter Notebook me run karna hai. Pehle code ko read karo, phir run karo, phir output observe karo. Teacher ko output ke baad explain karna hai ki input data kaise process hua and final result kaise bana.

import numpy as np
import pandas as pd

data = {"Name": ["Rahul", "Priya", "Aman"], "Hours": [5, np.nan, 7], "Score": [82, 74, 91]}
df = pd.DataFrame(data)
df["Hours"] = df["Hours"].fillna(df["Hours"].mean())
features = df[["Hours"]]
target = df["Score"]

print(df)
print(features)
print(target)

Expected Output

Clean DataFrame with missing Hours filled using mean, plus selected features and target.
