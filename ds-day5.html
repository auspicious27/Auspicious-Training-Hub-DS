Functions, parameters, return values, lambda, strings, lists, tuples, dictionaries, and sets

Introduction

Practical Code: Student Data Processing with Functions and Collections

Is practical ko Jupyter Notebook me run karna hai. Pehle code ko read karo, phir run karo, phir output observe karo. Teacher ko output ke baad explain karna hai ki input data kaise process hua and final result kaise bana.

def calculate_average(marks):
    return sum(marks) / len(marks)

student_name = "rahul sharma"
marks = [88, 76, 92, 81]
student_info = {"name": student_name.title(), "average": calculate_average(marks)}
unique_skills = {"Python", "Pandas", "Python", "ML"}

print(student_info)
print("Skills:", unique_skills)

Expected Output

{'name': 'Rahul Sharma', 'average': 84.25}
Skills: {'Python', 'Pandas', 'ML'}
