Understanding programming fundamentals and getting started with Python

Introduction

Welcome to Day 1 of Python for Data Science & Machine Learning! Today we'll explore what programming is, why Python is the top choice for data science, and set up your development environment. By the end of this day, you'll write your first Python program.

What is Programming?

Understanding Programming

Programming is the process of creating a set of instructions that tell a computer how to perform a task. Think of it as writing a recipe that a computer follows step by step.

Why Do We Need Programming?

  • Automation: Perform repetitive tasks quickly and accurately
  • Problem Solving: Break complex problems into manageable steps
  • Data Processing: Analyze and manipulate large datasets
  • Innovation: Build apps, websites, AI systems, and more
  • Career Growth: High demand in every industry

Real-World Analogy:

Imagine you're giving directions to someone who has never been to your house:

  1. Start at the main road
  2. Turn left at the traffic signal
  3. Walk 200 meters straight
  4. Turn right at the blue building
  5. My house is the 3rd one on the left

Programming is exactly like this — giving precise, step-by-step instructions to a computer!

Introduction to Python

What is Python?

Python is a high-level, interpreted, general-purpose programming language created by Guido van Rossum in 1991. It emphasizes code readability and simplicity, making it perfect for beginners and professionals alike.

Fun Fact: Python is named after the British comedy group "Monty Python" — not the snake!

Python Timeline

  • 1991: Python 1.0 released by Guido van Rossum
  • 2000: Python 2.0 released with list comprehensions
  • 2008: Python 3.0 released (major upgrade)
  • 2024: Python 3.12+ (current version)

Why Python for Data Science?

  • Simple syntax — reads like English
  • Rich ecosystem of data science libraries (NumPy, Pandas, Scikit-learn)
  • Largest community support
  • Used by Google, Netflix, Instagram, NASA
  • Free and open-source

Installing Python & Anaconda

Method 1: Installing Python Directly

  1. Visit python.org/downloads
  2. Download the latest version (Python 3.12+)
  3. Run the installer
  4. Important: Check "Add Python to PATH" during installation
  5. Click "Install Now"
  6. Verify: Open terminal and type python --version

Method 2: Installing Anaconda (Recommended for Data Science)

Anaconda is a complete data science platform that comes with Python + 250+ pre-installed packages.

Why Anaconda?

  • Comes with NumPy, Pandas, Matplotlib pre-installed
  • Includes Jupyter Notebook (interactive coding)
  • Easy package management with conda
  • No need to install packages individually

Anaconda Installation Steps:

  1. Visit anaconda.com/download
  2. Download for your OS (Windows/Mac/Linux) — ~700 MB
  3. Run installer → Choose "Just Me"
  4. Register Anaconda as default Python
  5. Complete installation (5-10 min)
  6. Open Anaconda Navigator to verify
Verify Installation: 
$ python --version
Python 3.12.0

$ conda --version
conda 23.7.4

Python Interpreter Basics

How Python Executes Code

Python is an interpreted language — it reads and executes code line by line, unlike compiled languages (C, Java) that convert entire code first.

SOURCE CODE

Your .py file

→

INTERPRETER

Reads line by line

→

OUTPUT

Results on screen

Interpreted vs Compiled:

  • Interpreted (Python): Executes line by line → Easier to debug, slower execution
  • Compiled (C/C++): Converts all code first → Harder to debug, faster execution

Python Execution Flow:

  1. You write Python code (.py file)
  2. Python interpreter reads the code
  3. Converts to bytecode (.pyc)
  4. Python Virtual Machine (PVM) executes bytecode
  5. Output is displayed
