Practical Code: Save and Load Model using Pickle

Is practical ko Jupyter Notebook me run karna hai. Pehle code ko read karo, phir run karo, phir output observe karo. Teacher ko output ke baad explain karna hai ki input data kaise process hua and final result kaise bana.

import pickle
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit([[1], [2], [3]], [10, 20, 30])

with open("saved_model.pkl", "wb") as file:
    pickle.dump(model, file)

with open("saved_model.pkl", "rb") as file:
    loaded_model = pickle.load(file)

print("Prediction:", loaded_model.predict([[4]])[0])

Expected Output

Prediction: around 40
